# Grim-inspired ClickGUI theme

This update adds a selectable `Grim Skid Theme` under the `Client Looks` category. It switches Sunshine's existing ClickGUI to a dark purple/charcoal palette while preserving Sunshine branding, module registration, settings, and layout behavior. The setting is persisted as `grimSkidTheme` in `config/sunshine.json`.

This is an original theme inspired by the requested visual direction; it does not copy Grim 4.4 source code or assets. An exact recreation would require a screenshot or source/reference for the specific Grim 4.4 interface.

Build and test with the project's configured Java 25 / Fabric Loom toolchain.
