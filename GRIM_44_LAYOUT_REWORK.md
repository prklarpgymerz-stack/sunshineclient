# Grim 4.4-inspired ClickGUI layout rework

This update changes the Grim Skid Theme from a mostly-colour-only variation to a different layout:

- two-column module grid with row-based scrolling
- narrower left category rail and more compact feature navigation
- dark charcoal cards with restrained purple active accents
- smaller module controls and no oversized letter tile in Grim mode
- the original Sunshine theme remains available when Grim Skid Theme is off

This is an independent, Grim 4.4-inspired design, not the original Grim Client source or assets. Build and in-game layout still need verification on the target Minecraft/Fabric environment.
