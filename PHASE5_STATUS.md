# Sunshine Client Phase 5 — Customization overhaul

Source update includes persistent Sprint Indicator controls (`sprintText`, `sprintColor`, `sprintTextSize`, `sprintX`, `sprintY`, `sprintBackground`), two visual profiles (Quality and Balanced), and removes the Performance profile from the mode cycle/UI label. Existing menu, module GUI, HUD editor, keybind screen, Freelook and CPS mixin sources are included.

Build/runtime verification has not been performed in this environment. These controls are persisted in `config/sunshine.json`; Sprint Indicator values can be edited there until a dedicated in-GUI form is wired in a future revision.
